# NgRx Signal Store Example

Sample project for my article *(link coming soon)*.

Demonstrates an Angular 21 app using **NgRx Signal Store** with:

- Signal-based state management (`signalStore`, `withState`, `withComputed`, `withMethods`, `withHooks`)
- Angular **Signal Forms** (`@angular/forms/signals`) for reactive form handling with built-in validation
- Filtered/computed user list driven by search query and role selection
- Inline edit form per user row

## Running locally

```bash
npm install
ng serve
```

Open `http://localhost:4200/`.

## Stack

- Angular 21
- NgRx Signals
- Tailwind CSS 4
